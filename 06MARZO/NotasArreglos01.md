# ARREGLOS
-Cada flotante tiene 4 Bytes de tamaño.


-Array: Conjunto de datos de un mismo tipo de datos.


-La etiqueta de un arreglo es una direccion de memoria que indica el inicio de la direccion


-La memoria empieza del numero mas alto a un numero mas bajo


-La direccion donde empieza es el indice [0] que llega hasta n-1 elementos del array


-Utilizamos una variable donde guardamos el tamaño del arreglo que se declara antes de delarar el arreglo  


-Las imagenes son matrices que se representan como RGB que utilizan arreglos tridimensionales


-Los arreglos de caracteres se les llama strings y agrega siempre un espacio extra que dictamina el fin del string \n


-Cuando trabajamos con arreglos de distintas dimensiones se piensan como un plano cartesiano donde cada cordenada guarda el valor
